Codexecutive

A Codex plugin marketplace carrying Orch Dork, governed delegation for Codex.

Orch Dork freezes a bounded plan of subagents before any work starts, keeps every worker inside its own lane with Codex hooks, and decides each run on host-computed evidence rather than on what a model says it did.

Install

codex plugin marketplace add jwj-eon/codexecutive
codex plugin add orch-dork@codexecutive

Then open Codex, review and trust the plugin's five hooks when Codex asks, and say "enroll this project with Orch Dork" in a chat. The skill walks you through the rest.

Orch Dork needs a local Codex with the app-server socket and plugin hooks; without them it runs in advisory mode and refuses to claim a governed result. Python 3.9 or later must be on PATH.
